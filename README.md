# Planer Treningów

Aplikacja desktopowa do planowania i monitorowania treningów, realizowana
w ramach przedmiotu **Programowanie Obiektowe**.

## Opis projektu
Aplikacja pozwala planować treningi, zapisywać ich wyniki i śledzić postępy.

## Funkcjonalności
- zarządzanie katalogiem ćwiczeń i sprzętu,
- tworzenie i edycja planów treningowych,
- rejestrowanie wykonanych treningów i serii,
- pomiary ciała i cele treningowe,
- podgląd postępów.

## Technologie
- C# / .NET 10
- WPF
- Microsoft SQL Server Express
